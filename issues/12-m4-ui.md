## Context
Depends on [M4-A].

## Tasks
- [ ] "Governance" tab: framework switcher (NIST / ISO / OWASP / ATLAS), compliance summary ring per framework (% compliant), controls table with status badge, linked findings count, priority, owner, due date.
- [ ] Control detail drawer: description, linked findings (click to open), evidence notes (add/edit), status change with comment, owner and due-date assignment.
- [ ] Remediation tracker (kanban or list): findings grouped by priority P1-P4 with status open/in_progress/resolved/accepted_risk; changing status updates DB and (later) the score.
- [ ] Heatmap: domain x framework coverage.
- [ ] Documentation-gaps panel listing missing governance documentation items.
- [ ] Tests for key components.

## Acceptance criteria
- [ ] User can change a control status, add evidence, assign owner/due date and see compliance percentages update.

Build the Governance tab in `web/` consuming the M4 API. Read `AGENTS.md`. Use Tailwind + Recharts, consistent with existing tabs. Provide a controls table with filters, a detail drawer with evidence notes, and a remediation tracker with status updates (optimistic UI + error rollback). Add component tests. Accessibility: keyboard-navigable drawer and table.
